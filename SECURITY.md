# Política de segurança

## Relatando uma vulnerabilidade

Não publique tokens, cookies, credenciais, IDs privados de projeto ou conteúdo exportado em issues públicas.

Ao relatar um problema de segurança:

- descreva o impacto;
- informe a versão afetada;
- forneça passos mínimos para reprodução;
- remova qualquer informação de autenticação.

## Escopo

Este userscript deve ser usado somente em projetos aos quais o usuário possui acesso legítimo. Ele não foi criado para contornar autenticação, autorização ou controles de acesso.
