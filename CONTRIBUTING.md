# Como contribuir

Obrigado pelo interesse em melhorar o Lovable Project Downloader.

## Antes de enviar uma alteração

- Teste apenas em projetos aos quais você possui acesso autorizado.
- Não inclua tokens, cookies, IDs privados ou arquivos exportados.
- Preserve a compatibilidade com Tampermonkey.
- Evite dependências externas sem necessidade.
- Mantenha mensagens da interface em português claro.

## Fluxo recomendado

1. Crie um fork.
2. Abra uma branch descritiva.
3. Faça alterações pequenas e focadas.
4. Valide a sintaxe do userscript.
5. Teste download, cancelamento, binários e falhas de rede.
6. Abra um pull request com:
   - problema resolvido;
   - solução aplicada;
   - testes realizados;
   - possíveis limitações.

## Relatórios de erro

Ao abrir uma issue, informe:

- navegador e versão;
- versão do Tampermonkey;
- versão do userscript;
- mensagem de erro;
- etapa em que ocorreu;
- logs sem dados sensíveis.
